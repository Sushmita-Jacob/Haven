🦔 HAVEN HedgeHop BOUNCE BACK 🦔

Cup pong-inspired game for Haven (theme: bounce back) --> goal: to bounce the hedgehog as many times as possible before bouncing into the cup!
You control the trampoline by using arrow keys to move Daven (the hedgehog). Daven BOUNCES off the trampoline and BOUNCES BACK after hitting the walls!
You lose when Daven falls off the trampoline OR off the screen and win when Daven is in the cup :D
