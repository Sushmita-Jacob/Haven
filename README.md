🦔 HAVEN HEDGEHOG BOUNCE BACK 🦔

cup pong-inspired game for Haven (theme: bounce back) --> goal: to bounce the hedgehog as many times as possible before bouncing into the cup!
You control Daven (the hedgehog) by using arrow keys. Daven BOUNCES off the trampoline and BOUNCES BACK after hitting the walls!
You loe when Daven falls off the trampoline OR off the screen and win when Daven is in the cup :D
